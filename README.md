# Roofline

Rent rooftops and scenic spaces by the hour in Hoboken and NYC, without owning any property.

This repo holds the interactive prototype (front-end mockups) for our group project.

## Pages

| File | What it shows |
|---|---|
| `index.html` | Landing page linking to both flows |
| `host.html` | Host flow: space details, photo upload, hourly rate, availability calendar |
| `guest.html` | Guest flow: search and filters, time slots, checkout, confirmation |

## Run it locally

No build step or dependencies. Open `index.html` in a browser.

## Notes

- This is a mockup. No data is saved, and no real payments or accounts exist.
- Listings and photos on the guest side are sample data.
- Fonts load from Google Fonts and fall back to system fonts if offline.
